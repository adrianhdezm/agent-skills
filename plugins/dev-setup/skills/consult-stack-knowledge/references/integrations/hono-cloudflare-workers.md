# Hono + Cloudflare Workers

A Hono app as the Worker: workerd drives `app.fetch`, the bindings are typed by Wrangler, and tests reach the Worker
through its real entry. The Hono Worker and React Router on Workers use it.

## The seam

```
wrangler.jsonc ─► wrangler types ─► worker-configuration.d.ts (Env)
                                          │
workerd ─► main (the Hono app's default export) ─► app.fetch ─► handlers read c.env, c.executionCtx
```

- **The Hono app is the Worker's `main`**, exported as the default; workerd calls its `fetch`. The build tool's
  integration (Cloudflare Workers + Vite) serves and builds it.
- **Bindings are typed by the runtime**: `new Hono<{ Bindings: Env }>()`, where `Env` comes from `wrangler types`; `c.env`
  in handlers — from the first commit, even with no binding yet, so adding one changes no app code.

## Where it lives

| File                        | Holds                                                                    |
| --------------------------- | ------------------------------------------------------------------------ |
| `wrangler.jsonc`            | `main` pointing at the Hono entry (`./src/app.ts` or `./workers/app.ts`) |
| `worker-configuration.d.ts` | the generated `Env` the app's `Bindings` use                             |
| the entry file              | `new Hono<{ Bindings: Env }>()`, `export default app`                    |

## Pitfalls

- **Hono's `c.executionCtx` is typed with Hono's own `ExecutionContext`**, which lacks members newer Workers types add
  to the global one. Pass it on typed as `Context['executionCtx']` from `hono`, not as the global `ExecutionContext`.
- **An un-awaited promise in a Worker is cut off when the response returns**: `await` it, or hand it to
  `c.executionCtx.waitUntil()`.

## Conventions

- **Bindings and configuration are typed**: `Hono<{ Bindings: Env }>` with `Env` generated by Wrangler; never hand-write
  `Env`.
- **Floating promises are errors**: await them, or `c.executionCtx.waitUntil()`.

## Verify it is wired

- `wrangler.jsonc`'s `main` is the file whose default export is the Hono app.
- The app is `Hono<{ Bindings: Env }>` and no file declares its own `Env` interface.
