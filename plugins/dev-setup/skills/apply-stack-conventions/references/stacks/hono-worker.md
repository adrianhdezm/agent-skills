## Shape

```
my-worker/
├── .gitignore / .prettierignore / .prettierrc
├── coding-conventions.md      # assembled from the stack blueprint
├── eslint.config.js
├── package.json / pnpm-lock.yaml / pnpm-workspace.yaml
├── tsconfig.json              # solution file
├── tsconfig.cloudflare.json   # src/, runs in workerd
├── tsconfig.node.json         # vite.config.ts, vitest.config.ts: run in Node
├── tsconfig.test.json         # src/ + tests/, workerd plus the test runtime types
├── vite.config.ts / vitest.config.ts
├── worker-configuration.d.ts  # generated by `wrangler types`; committed
├── wrangler.jsonc
├── src/app.ts                 # the Hono app, default export
└── tests/app.test.ts          # one per module in src/, same name
```

| `wrangler.jsonc`  | `main: "./src/app.ts"`                                                                                                                                                                                                                                                                                                             |

`vite.config.ts`:

```ts
import { cloudflare } from '@cloudflare/vite-plugin';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [cloudflare({ viteEnvironment: { name: 'worker' } })],
  resolve: { tsconfigPaths: true },
  environments: { worker: { build: { sourcemap: true } } }
});
```

`vitest.config.ts`:

```ts
import { cloudflareTest } from '@cloudflare/vitest-plugin';
import { defineConfig } from 'vitest/config';

export default defineConfig({
  plugins: [cloudflareTest({ wrangler: { configPath: './wrangler.jsonc' } })]
});
```

## Scaffold

- **Check the Cloudflare Vitest plugin's peer range** before installing `vitest`.
- **Run `pnpm cf-typegen`** once the configs are written, before the first check.
- **Into an existing project**: configs copied from a Cloudflare or React Router template usually need `DOM` and
  `vite/client` removed, `composite` replaced by `noEmit` plus `tsBuildInfoFile`, `include` pointed at `src/`, and `jsx`,
  `paths`, `rootDirs` and `esModuleInterop` dropped.

## Conventions

### Layout

- **`src/app.ts` is the Worker**: the Hono app, exported as the default. Routes grow there or in modules it imports,
  one test file per module in `tests/`.
- **No DOM types**: the Worker's globals come from `worker-configuration.d.ts` alone.

### Commands

`pnpm dev` runs the Worker in workerd; `pnpm preview` runs the build; `pnpm deploy` ships it. `pnpm typecheck`,
`pnpm lint`, `pnpm test`, `pnpm build` and `pnpm format:check` are the five required checks.

## Smoke test

`pnpm exec vite preview --port <free port>` serves the build in workerd; with the example, `GET /` answers
`Hello Cloudflare Workers!`.
